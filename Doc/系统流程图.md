## 用户认证流程

### 用户注册流程

```mermaid
sequenceDiagram
    participant 用户
    participant 前端
    participant 后端API
    participant 数据库
    
    用户->>前端: 填写注册信息
    前端->>前端: 表单验证
    前端->>后端API: POST /api/auth/register
    后端API->>数据库: 检查用户名/邮箱是否存在
    数据库-->>后端API: 返回检查结果
    
    alt 用户名或邮箱已存在
        后端API-->>前端: 返回错误信息
        前端-->>用户: 显示错误信息
    else 可以注册
        后端API->>后端API: 生成盐值和密码哈希
        后端API->>数据库: 创建用户记录
        后端API->>数据库: 创建用户-角色关联
        数据库-->>后端API: 返回成功
        后端API-->>前端: 返回成功信息
        前端-->>用户: 显示注册成功，引导登录
    end
```

### 用户登录流程

```mermaid
sequenceDiagram
    participant 用户
    participant 前端
    participant 后端API
    participant 数据库
    
    用户->>前端: 输入用户名/邮箱和密码
    前端->>后端API: POST /api/auth/login
    后端API->>数据库: 查询用户信息
    数据库-->>后端API: 返回用户数据(含盐值和密码哈希)
    
    alt 用户不存在
        后端API-->>前端: 返回错误信息
        前端-->>用户: 显示错误信息
    else 用户存在
        后端API->>后端API: 验证密码
        
        alt 密码错误
            后端API-->>前端: 返回错误信息
            前端-->>用户: 显示错误信息
        else 密码正确
            后端API->>数据库: 查询用户角色
            数据库-->>后端API: 返回角色信息
            后端API->>后端API: 生成JWT令牌
            后端API-->>前端: 返回token和用户信息
            前端->>前端: 存储token
            前端-->>用户: 重定向到主页
        end
    end
```

### 访问保护资源流程

```mermaid
sequenceDiagram
    participant 前端
    participant JWT中间件
    participant 角色验证中间件
    participant API处理器
    participant 数据库
    
    前端->>JWT中间件: 请求(带Authorization头)
    JWT中间件->>JWT中间件: 验证token
    
    alt Token无效或过期
        JWT中间件-->>前端: 401 Unauthorized
    else Token有效
        JWT中间件->>JWT中间件: 解析用户ID和角色
        JWT中间件->>角色验证中间件: 转发请求(附加用户信息)
        角色验证中间件->>角色验证中间件: 检查用户角色权限
        
        alt 权限不足
            角色验证中间件-->>前端: 403 Forbidden
        else 权限充足
            角色验证中间件->>API处理器: 转发请求
            API处理器->>数据库: 执行业务逻辑
            数据库-->>API处理器: 返回数据
            API处理器-->>前端: 返回处理结果
        end
    end
```

### 第三方登录流程

```mermaid
sequenceDiagram
    participant 用户
    participant 前端
    participant 第三方服务
    participant 后端API
    participant 数据库
    
    用户->>前端: 点击第三方登录按钮
    前端->>第三方服务: 重定向到授权页面
    第三方服务->>用户: 显示授权页面
    用户->>第三方服务: 授权访问
    第三方服务->>前端: 重定向回应用(携带code)
    前端->>后端API: POST /api/auth/oauth/{provider}
    后端API->>第三方服务: 使用code换取access_token
    第三方服务-->>后端API: 返回access_token
    后端API->>第三方服务: 获取用户信息
    第三方服务-->>后端API: 返回用户信息
    
    后端API->>数据库: 查询是否有关联账号
    数据库-->>后端API: 返回查询结果
    
    alt 已有关联账号
        后端API->>数据库: 获取用户信息和角色
        数据库-->>后端API: 返回用户数据
    else 无关联账号
        后端API->>后端API: 生成随机密码
        后端API->>数据库: 创建新用户
        后端API->>数据库: 创建用户-角色关联
        后端API->>数据库: 创建OAuth关联记录
        数据库-->>后端API: 返回新用户数据
    end
    
    后端API->>后端API: 生成JWT令牌
    后端API-->>前端: 返回token和用户信息
    前端->>前端: 存储token
    前端-->>用户: 重定向到主页
```

```mermaid
sequenceDiagram
    participant 用户

    participant API服务
```
