## 基础信息

### 基本URL格式
```
http://{服务器地址}/api/v1/{资源类别}/{操作}
```

### 请求格式
- Content-Type: application/json

### 响应格式
所有API响应都采用统一的JSON格式：
```json
{
  "code": 200,       // 状态码，200表示成功，非200表示失败
  "message": "成功", // 状态描述
  "data": {}         // 响应数据，可能是对象、数组或null
}
```

### 错误码说明
- 200: 成功
- 400: 请求参数错误
- 401: 未授权/登录失效
- 403: 权限不足
- 404: 资源不存在
- 500: 服务器内部错误

## 认证相关

### 注册
- **URL**: `/api/v1/auth/register`
- **方法**: POST
- **描述**: 用户注册
- **权限**: 无需认证
- **请求参数**:
```json
{
  "username": "student1",
  "password": "password123",
  "email": "student1@example.com",
  "role": "student"  // student/teacher/admin
}
```
- **响应示例**:
```json
{
  "code": 200,
  "message": "注册成功",
  "data": {
    "user_id": 1,
    "username": "student1"
  }
}

{
  "code": 409,
  "message": "用户名或邮箱已存在",
  "data": null
}

{
  "code": 400,
  "message": "请求参数错误",
  "data": {
    "errors": {
      "username": ["用户名不能为空", "用户名长度必须在3-20个字符之间"],
      "password": ["密码不能为空", "密码长度必须在6-20个字符之间"],
      "email": ["邮箱格式不正确"]
    }
  }
}

{
  "code": 403,
  "message": "权限错误",
  "data": {
    "error": "只允许学生角色注册，管理员和教师角色需要由系统管理员分配"
  }
}

{
  "code": 500,
  "message": "服务器内部错误",
  "data": null
}
```
